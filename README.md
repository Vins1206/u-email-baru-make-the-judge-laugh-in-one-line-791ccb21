One funny line about email, in one line only — written for the
[make.fun bounty](https://make.fun/bounty/u-email-baru-make-the-judge-laugh-in-one-line-791ccb21).

## The line

> I finally reached inbox zero, then my inbox sent me a welcome-back email.

## How to run

```sh
python3 main.py
```

This writes exactly one line of plain text to `/output/entry.txt`
(73 characters, no trailing newline). Python standard library only —
no network, no dependencies.

## How it was picked

Five one-line candidates were drafted and scored against the judge's
rubric (one-read funny, surprise, tightness, freshness, clean read).
The inbox-zero reversal won: the setup promises a victory, the
punchline takes it straight back, and the laugh lands on the last words.
